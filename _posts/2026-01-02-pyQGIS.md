### The Problem: Invisible Data Gaps
In large geospatial datasets, "empty" cells often hide behind invisible characters or QGIS-specific `NULL` variants. Standard data analysis tools frequently fail to count these as missing values, leading to inaccurate data quality reports.

### The Solution: A Deep-Cleaning PyQGIS Script
I developed a Python script that runs directly within QGIS to audit attribute tables. It performs three critical tasks:

1.  **Strict Null Detection:** It identifies `QPyNullVariant`, empty strings, and whitespace-only cells that standard tools miss.
2.  **Automated Export:** It generates a high-level bar chart for immediate visual feedback and exports the full cleaned dataset to Excel.
3.  **Dynamic Styling:** The script automatically categorizes the layer based on a user-selected column, applying a 40% transparency to improve map legibility.
