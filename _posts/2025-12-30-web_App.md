This project implements an automated end-to-end data pipeline to analyze the Geneva Airbnb market. It correlates rental pricing with urban infrastructure density using OpenStreetMap data.

### **Key Engineering Features**
* **Automated ETL Pipeline:** A custom Python engine that handles data ingestion from InsideAirbnb (CSV.GZ) and geospatial features via the OSMnx API.
* **Local Data Warehousing:** Implemented a **SQLite** backend to persist cleaned listings and Point of Interest (POI) data, ensuring decoupled data processing and visualization.
* **Geospatial Feature Engineering:** Utilizes the `shapely` and `osmnx` libraries to calculate centroids and consolidate diverse OSM tags (amenities, transport, shops) into a unified relational schema.
* **Data Pre-processing:** Automated cleaning of currency strings to numeric formats and handling of missing geospatial metadata for over 4,000+ local features.

### **Tech Stack**
* **Database:** SQLite, SQL
* **ETL/Analysis:** Python (Pandas, OSMnx, Requests, SQLite3)
* **Frontend:** Streamlit, Folium (Leaflet) NumPy, Matplotlib/Plotly
