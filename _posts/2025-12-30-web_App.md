This project features an end-to-end data pipeline and interactive dashboard designed to analyze the Geneva short-term rental market by correlating Airbnb pricing with urban infrastructure.

### **Core Functionalities**
* **Automated Data Acquisition:** Developed a custom Python ETL engine that programmatically scrapes and cleanses Airbnb listing data from regional sources.
* **SQL Data Architecture:** Implemented a robust SQL database to store historical snapshots of Airbnb availability and pricing, enabling longitudinal trend analysis.
* **Interactive Geospatial Dashboard:** A Streamlit interface using dual-layer Leaflet maps to visualize the distribution of rentals (supply) against local amenities (demand).
* **Proprietary Scoring Algorithm:** Engineered a "Convenience Index" metric that quantifies the proximity of essential services to each Airbnb listing.
* **Market Insights:** Dynamic visualization of the relationship between nightly rates and proximity to Geneva’s central business district and transport hubs.

### **Tech Stack**
* **Frontend:** Streamlit, Folium (Leaflet)
* **Data Engineering:** Python (Requests, BeautifulSoup, Pandas)
* **Storage:** SQL (PostgreSQL/SQLite), SQLAlchemy
* **Analysis:** NumPy, Matplotlib/Plotly
